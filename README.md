# 📊 Automação e Análise de Vendas com Python

Uma solução automatizada em Python para geração de dados fictícios de vendas, análise de faturamento/métricas, exportação de relatórios consolidados em Excel e geração de gráficos estatísticos.

## 📌 Funcionalidades

- **Geração de Dados:** Script para gerar massa de dados fictícia (`vendas_ficticias.xlsx`).
- **Análise & Métricas:** Cálculo automático de:
  - Faturamento Total
  - Total de Unidades Vendidas
  - Ticket Médio por Venda
- **Relatório Consolidado:** Exportação tratada para Excel com múltiplas abas (`Por Produto`, `Por Regiao`, `Evolucao Mensal`).
- **Visualização de Dados:** Geração de gráfico de barras com rótulos de valores salvos em alta resolução (`faturamento_por_produto.png`).
- **Tratamento de Exceções:** Manipulação segura para erros de arquivos ausentes, vazios ou bloqueados pelo sistema.

---

## 🛠️ Tecnologias Utilizadas

- **Python 3**
- **Pandas** (Tratamento e manipulação de dados)
- **Matplotlib** (Visualização e geração de gráficos)
- **OpenPyXL** (Manipulação de arquivos `.xlsx`)
- **Ruff** (Linter e formatador de código para boas práticas PEP 8)
